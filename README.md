# Alur Program
1. ketika user menjalankan kode akan di tampilkan halaman login.
2. jika user tidak memiliki akun bisa melakukan register.
3. setelah user login maka akan di tampilkan home page.
4. di tampilkan daftar makanan, jika user meng klik gambar makanan maka akan di tampilkan detail dari makanan tersebut.
5. di tampilan detail user bisa memesan makanan dan akan masuk ke cart.
6. user juga bisa melakukan search nama(title) dari makanan.
7. jika user pergi ke halaman cart, user bisa melakukan checkout.
8. ketika checkout user akan ditampilkan mau membayar dengan cara apa.
9. setelah memilih user bisa bayar.
10. setelah bayar maka akan di tampilkan status pesanan.
11. status pesanan akan secara otomatis memilih pesanan di terima atau di tolak, jika statusnya di terima maka akan menampilkan status makanan sedang di jalan dan sampai.
